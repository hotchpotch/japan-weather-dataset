# v0.1.0

First release of the image `ghcr.io/hotchpotch/japan-weather-dataset:v0.1.0`.

## Dataset

- Daily (1872–) and hourly values of all JMA stations, with station lists
  and homogeneity breaks, as Parquet with a dataset card.
- The month of the latest day and the month before are month files
  (`year=YYYY/YYYY-MM.parquet`); older rows are year files. `manifest.json`
  lists the latest day and each month file with its rows and missing days.
- Each row has `updated_at`, the time its values last changed.

## Updates

- `jwd month` updates the current month from the dataset files alone: the
  last 3 days again and up to 3 missing days before them (exit code 7 when
  more are missing). `scripts/jwd-daily.sh` downloads, runs it and uploads;
  `.github/workflows/month.yml` runs it daily in this image.
- `jwd monthly` on the machine with the crawl state: stations, the last two
  months again after they ended, 1/24 of the older station-years again,
  export. `scripts/jwd-monthly.sh` runs it and uploads;
  `scripts/jwd-docker.sh` runs it in this image.
- The pause between requests adapts to the server: 6 s at the start, down
  to 3 s (5 s in the scheduled runs) while nothing is rate limited, doubled
  on rate limiting.
- `jwd version` prints the version.
