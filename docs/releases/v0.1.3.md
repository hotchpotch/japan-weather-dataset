# v0.1.3

## Image tag `latest`

- A release also tags its image `ghcr.io/hotchpotch/japan-weather-dataset:latest`.
  The daily and monthly workflows run `:latest`, so a release takes effect
  with their next run instead of after switching `JWD_IMAGE`. Version tags
  stay fixed; [docs/release.md](../release.md) describes how to point
  `latest` back to an earlier version.

## Using the dataset

- New [docs/local-copy.md](../local-copy.md): how fresh the Hub is, how to
  keep a local copy up to date, and how to fetch days newer than the Hub
  with `jwd month` (Go or Docker).
- New agent skill `japan-weather` (`.agents/skills/japan-weather/`, linked
  from `.claude/skills/`) for Claude Code and Codex: coverage, daily vs
  hourly, downloads (`sync.sh`, into `~/.cache/japan-weather/data`), the
  columns, SQL recipes and pitfalls of long-term comparisons.
- The dataset card links to both and no longer says that older years are
  refreshed on a rolling basis (the updates do not refetch them).
